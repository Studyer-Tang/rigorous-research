# Computational evidence

## Reproducibility record

For decisive computation, record:

- exact input and expected output;
- source files and checksums or immutable revision;
- software, version, operating assumptions, and dependencies;
- coefficient domain and parameter restrictions;
- deterministic seed or a description of randomness;
- resource bounds and termination condition;
- machine-checkable raw output, not only screenshots or prose summaries.

Keep exploratory code separate from the minimal verification script.

## What computation establishes

State the logical bridge from output to theorem. Exhaustive finite search requires a proved finite search space. Symbolic output requires a specified ring and valid simplification rules. Numerical evidence does not prove exact equality or nonvanishing without certified error bounds or an exact reconstruction argument.

## Independent checks

Prefer at least one structurally different check for a decisive result:

- direct substitution versus normal-form reduction;
- two independent implementations;
- exact arithmetic versus certified modular images;
- hand verification of small cases and boundary cases;
- randomized identity testing only as error-bounded evidence, clearly labeled.

Do not call two prompts to the same model independent verification when they reuse the same unverified derivation.

## Failure and provenance

Preserve failing examples, logs, and the first version that produced the result. Report timeouts and excluded cases. If code was generated by AI, review the implementation and tests as code; model authorship neither validates nor invalidates it.
