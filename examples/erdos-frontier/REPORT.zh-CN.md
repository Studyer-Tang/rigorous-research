# Erdős–Straus：多路线尝试与 Agent 1.12 实战改进

2026-09-08。**原猜想未解决：没有获得全称证明，也没有找到原猜想的反例。** 本轮否定了几个自己提出的加强版辅助猜想，重建并机器核验了已知的部分同余覆盖，给出一个可审阅的解提升引理，并把实际缺失的整数研究能力补入 Agent。以下不声称新颖性、突破计算纪录或具备发表条件。

## 原目标与使用方式

经典 Erdős–Straus 猜想询问每个整数 n≥2 是否有正整数分母，使 4/n=1/x+1/y+1/z，允许分母重复。项目沿用更强的 n≥3、x<y<z 版本；本轮得到的互异分母解当然也满足经典等式，但强版本的失败不能自动反驳经典版本。

当前 Codex 实时选择提案，经项目 Agent 的共享内核执行并保存行动；没有使用预写模型回复冒充自主推理，没有另行调用模型 API。Skill 负责组织主命题、辅助路线、反证和证明义务。确定性搜索脚本只是执行宿主选定的实验，不负责模拟模型决策。

文献检索使用 Agent 的 arXiv 接口，查询 `Erdos Straus conjecture polynomial identities congruence classes`，限 5 项，结果含无关条目。进一步实际阅读了 Miguel Angel Lopez 的预印本 [A Complete Congruence System for the Erdos-Straus Conjecture, arXiv:2404.01508v3](https://arxiv.org/html/2404.01508v3)，见 [读取记录](literature/source.json)。它讨论同余路线及 Mordell 的限制，仍提出辅助猜想。本文没有把标题当作已完成证明；关于 Mordell 的介绍也没有冒充独立核验的原始证明。检索不是完整的最新状态或新颖性审计。

## 路线一：小窗口贪心假说被精确否定

由余项必须为正，最小分母必有 x>n/4。本轮提出的辅助假说 H_K 是：对每个 n≡1 (mod 24)、n≥25，前 K 个候选 x=⌊n/4⌋+1,…,⌊n/4⌋+K 至少有一个可以完成互异分解。H_K 是本轮的探索性加强假说，不是另一个已命名的公开未解猜想。

结果：

| n | 最初连续失败的候选数 | 精确最小 x | 找到的 y | 找到的 z |
|---:|---:|---:|---:|---:|
| 1129 | 2 | 285 | 29260 | 99103620 |
| 1201 | 5 | 306 | 15980 | 172727820 |
| 246241 | 9 | 61570 | 388745120 | 4499074393414240 |

因此 H₂、H₃、H₄、H₅、H₈、H₉ 等加强假说被相应例子否定。我们没有证明“对每个固定 K 都会失败”，也没有声称表中第三个 n 是全局最小的 H₈ 反例。

这些不是搜索失败猜测。将 4/n−1/x 约成 a/b 后，任意有序完成解都对应

\[
(ay-b)(az-b)=b^2,\qquad 0<ay-b\le b.
\]

检查器独立核验 b 的完整素因数分解，枚举 b² 的全部正因子 d≤b，逐一检查 d+b 与 b²/d+b 是否均被 a 整除，再检查 x<y<z。没有遗漏可能解的因子；非正余项则直接不可能。表中每个最小 x 之前的所有正余项候选均有完整障碍证书。

H₈ 曾通过 25,…,99985 中全部 4166 个 n≡1 (mod 24)。随后按文献提示选择较难的模 840 类作定向搜索，才在 246241 找到失败。累计检查 H₈ 的 4597 个不同输入。这给出了很具体的教训：连续数千次成功仍不能替代一般论证。

证据：行动 7–12、14–33；[独立汇总](window-summary.json)。失败窗口之外均有明确解，所以这些例子不反驳原猜想。

## 路线二与三：改变公式结构，重建部分同余覆盖

先对 n=840t+c、c≡1 (mod 24)，取 x=(n+r)/4、r=4k−1、k=1,…,64，令 B=nx，尝试固定正整数 d：

\[
y=(B+d)/r,\qquad z=(B+B^2/d)/r.
\]

生成器枚举 B² 系数最大公因数的约数，筛选整数多项式和正性条件。这一受限 Ansatz 仅找到 35 个目标类中的 23 个；未找到公式不等于该类无解。初次本地调用还暴露了 SymPy 整数系数域不能直接乘有理数的问题，改为明确使用有理系数域后，工作区 R001 成功，保留了修正说明。

随后根据缺口改变结构，使用与 B 成比例的因子，以及允许余项分子变化的构造。例如 n=7c−2 时取 x=2c、y=2n、z=cn，得到 4/n；在本轮相应进程的起点上 c>2，分母严格递增。这补上另外 6 类。见 [初次候选](family-candidates.json)、[扩展候选](family-candidates-v2.json)，以及 R002。

Agent 对 29 个模 840 类逐一核验完整参数族（行动 35–63），再核验另外 23 个模 24 的基础类（行动 69–91）。这里已包括 n≡9 (mod 24) 的缩放构造，以及最小 n≥3 的边界处理。

每个证书证明：对**所有非负整数 t**，n(t)、x(t)、y(t)、z(t) 是正整数，x(t)<y(t)<z(t)，且精确满足等式。验证器不调用 SymPy 或生成器，而是独立进行整数多项式运算，检查

\[
4xyz-n(xy+xz+yz)=0
\]

的每个系数；再用 n−1、x−1、y−x−1、z−y−1 的非负系数证明正性与顺序。整数系数保证整性。这是充分的证明方法，不是所有正多项式的完备判定器。

对这些等差数列另作模 840 的完整覆盖检查，并确认每族从该类中最小的 n≥3 开始，没有遗漏有限前缀。得到的部分结论是：

> 每个 n≥3，只要 n 模 840 不属于 {1,121,169,289,361,529}，就有一个已核验的互异分母构造。

这覆盖 834/840 个类，但剩余 6 类仍各有无限多个整数；“99% 以上的类”不是全称证明。该缺口与所读文献列出的经典部分结果一致，不是新的模数覆盖纪录。

## 路线四：由单个精确解提升到无限参数族

**引理（文字证明，无新颖性主张）。** 设 n₀,x₀,y₀,z₀ 是一个正整数解且 x₀<y₀<z₀。令

\[
r=4x_0-n_0,\quad b_0=n_0x_0,\quad d=ry_0-b_0.
\]

余项正性保证 r>0；由 1/y₀<r/b₀ 得 d>0。原等式还给出 d(rz₀−b₀)=b₀²。对任意整数 t≥0，定义

\[
N=n_0+4rdt,\quad X=x_0+rdt,\quad B=NX,
\quad Y=\frac{B+d}{r},\quad Z=\frac{B+B^2/d}{r}.
\]

则 N,X,Y,Z 都是正整数，X<Y<Z，并满足 4/N=1/X+1/Y+1/Z。

证明：4X−N=r；而

\[
B-b_0=rd(n_0+4x_0)t+4r^2d^2t^2
\]

是 rd 在整数多项式环中的倍数。因此 Y 的非常数系数均为整数，常数项为 y₀；Z 同理，因为 (B²−b₀²)/(rd) 与 (B−b₀)/r 均为整数多项式，其常数项为 z₀。恒等式 (rY−B)(rZ−B)=B² 给出所需倒数和。

X 显然为正；Y−X 的常数项为 y₀−x₀>0，线性系数为 2dn₀>0，二次系数为 4rd²>0。Z−Y=(B²/d−d)/r 的常数项为 z₀−y₀>0，其他系数非负。故对所有 t≥0，严格顺序成立。证毕。

本轮将表中的三个解实际代入并独立核验（行动 65–67）：

| 经过的已知解 | N(t) | X(t) |
|---:|---|---|
| 1129 | 1129+4180t | 285+1045t |
| 1201 | 1201+3128t | 306+782t |
| 246241 | 246241+204360t | 61570+51090t |

完整 Y、Z 系数见 [提升参数族](lifted-families.json)。例如第一族

\[
Y=29260+215555t+397100t^2,
\]
\[
Z=99103620+1460385125t+8070389745t^2+19822437800t^3+18258658000t^4.
\]

这给出了真正对无限多个输入成立的具体公式，包含最初小窗口策略失败的输入。但引理的前提是**已经有一个解**，没有提供覆盖所有 n 的下降或归纳步骤。因此它也没有解决原猜想。

## 架构实际改进与限制

1. 原来 Agent 无法调用项目已有整数搜索，本轮增加 `egyptian`；并加入 `egyptian_window`、`egyptian_scan`，用完整因子枚举区分真正的窗口反证和预算耗尽。
2. 原来只能核验参数公式的有理恒等式，本轮加入 `egyptian_family`，同时检查参数量词、整性、正性和严格顺序。正性证明方法不适用时保持未决。
3. 原来几十步后旧证明义务容易离开近期记录，本轮加入有长度限制、文件哈希和明确截断提示的 `research_memory`，让模型继续看到工作区任务和证明义务。记录不会自行变成已接受的证明。
4. 全部新工具共用已有宿主/API/MCP 内核、时间预算、独立检查和原目标状态；没有另写一套“研究成功”判定器。

仍需实时模型提出可证伪假说、推导新构造、阅读论文和判断值得尝试的路线。本轮公式候选生成由宿主编写的实验脚本完成，并非 API 动作集合中的通用公式发现器。没有同模型同预算的能力对照，不能据此给架构的“科研智力”打分。

## 当前边界与复算

原猜想和更强的项目版本都保持未决；一般提升引理是文字证明，没有形式化编译或真实人工审稿记录。55 个具体参数族经过独立证书检查，其中 52 个参与上述模 840 的部分覆盖，另外 3 个是提升族。

行动 JSON、原始候选、执行日志和汇总可复查。研发过程中的工具哈希随版本修改变化，行动保留当时哈希；复算使用最终代码重新验证数学内容，不声称逐字节重建每一步的历史环境。运行 `python examples/erdos-frontier/reproduce.py` 可重查证据并重跑代表性工具；这属于记录重放，不是再次进行自主科研。

下一步最需要的是针对剩余类的、随输入变化的构造或有良基度量的下降论证。扩大有限搜索和增加固定参数族可以辅助发现，但本轮已经实际说明了它们不能自行填补全称量词。
