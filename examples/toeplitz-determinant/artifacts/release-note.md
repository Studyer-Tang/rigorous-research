# Release note

The parameterized determinant identity is supported over \(\mathbb Z[\rho]\) for every integer \(n\ge1\). The decisive evidence is a division-free row-operation proof. Exact symbolic and rational computations use different algorithms and cover boundary and singular parameter values, but are diagnostic rather than substitutes for the proof.

This worked example demonstrates conjecture testing, coefficient-domain auditing, proof construction, independent recomputation, adversarial boundary analysis, evidence-role separation, and release gating in one research workspace.
